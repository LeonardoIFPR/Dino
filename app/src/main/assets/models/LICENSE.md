# Modelos e créditos

`ammonite.glb`, `trilobite.glb`, `tooth.glb` e `bone.glb` foram gerados
originalmente para Fósseis pelo Mapa pelo script `scripts/generate_models.py`.
São ilustrações estilizadas, não digitalizações de fósseis científicos.

Estes quatro modelos são disponibilizados sob **CC0 1.0 Universal**:
https://creativecommons.org/publicdomain/zero/1.0/

## Modelos fornecidos pelo responsável pelo projeto

Os oito originais ficam em `modelosGLB/` e não foram modificados. A origem,
autoria e licença dos novos arquivos ainda não foram informadas. A licença CC0
acima se aplica somente aos quatro modelos originais gerados pelo projeto.

| Original | Cópia preparada para o aplicativo |
| --- | --- |
| cabeça_triceratops.glb | triceratops_head.glb |
| corpo_triceratops.glb | triceratops_body.glb |
| cranio_t_rex.glb | trex_head.glb |
| corpo_t_rex.glb | trex_body.glb |
| cabeça_carnotauro.glb | carnotaurus_head.glb |
| corpo_carnotauro.glb | carnotaurus_body.glb |
| personagem feminino.glb | explorer_female.glb |
| personagem_masculino.glb | explorer_male.glb |

Processamento das cópias: redução de malha com meshoptimizer, conversão de WebP
para PNG/JPEG, redução de texturas e nomes de malha `head`, `body`, `explorer`.
Os arquivos `triceratops.glb`, `trex.glb` e `carnotaurus.glb` são composições para
exposição com esqueleto completo e crânio separado ao lado, conforme a escolha
do responsável pelo projeto. Não representam encaixes anatômicos entre os arquivos.
As miniaturas foram renderizadas a partir desses mesmos modelos.
Os retratos `explorer_female_portrait.png` e `explorer_male_portrait.png` são
renderizações das malhas originais, feitas por `scripts/render-explorer-portraits.py`.
Usam rasterização de triângulos e textura em uma câmera enquadrada na cabeça.
